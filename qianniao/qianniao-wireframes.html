双角色：酒店商家端（发单 / 维保 / 签约续费） × 全职工程师端（派单 / 施工 / 绩效） · 共 25 页 · v2.0（含客户反馈修订）

虚线灰盒 = 内容/图片占位 蓝色 = 主行动按钮/选中态 深蓝实色 = 强调卡片 底部栏 = TabBar
公共入口 (3) 酒店商家端 (13) 维修师傅端 (8) 公共平台 (1) 附：公司端后台

公共入口

首次进入小程序的登录与身份分流，所有用户共用。

P1 微信授权登录 → P2 角色选择 → P3 资料完善 → 进入对应端首页（H1 / M1）

酒店商家端

酒店发起报修工单、跟踪进度、管理维保档案、电子签约与续费。

签约充值闭环：H12 电子签约 → H10 充值续费 → H1 首页 → H2 发起报修 → H4 工单详情（看进度 / 服务群沟通）→ H6 当日汇总评价（按日/次统计）；每酒店配专属服务群 H13

维修师傅端

全职自有工程师：管理员按酒店分配负责工程师，系统按负责关系自动派单，无需抢单。

管理员分配酒店 → 酒店发单自动派给负责工程师 → M2 派单任务 → M3 确认接收 → M4 施工上报 → M5 完工提交 → 酒店验收后计入 M7 绩效统计（按日/次）

公共平台

酒店圈信息交流、招聘与广告，双端均可访问（TabBar 入口）。

附：公司端（建议做 Web 管理后台，不进小程序）

思维导图中的「公司端」面向平台运营方，功能为数据管理而非高频操作，建议以 Web 后台承载：

· 工程师分配：管理员为每家酒店指派 1 名负责工程师（全职自有制），支持调整/改派
· 质量监控：差评工单预警、评价汇总（按日/次为单位统计，与酒店端评价口径一致）、响应/完工时长统计
· 工单调度：按负责酒店自动派单，支持管理员手动指派与改派、紧急工单升级
· 签约与财务：电子合同模板管理、签约状态查看、酒店续费记录、材料费用对账
· 服务群管理：每酒店专属服务群创建与成员管理（工程师 / 客服 / 运营）
· 内容运营：酒店圈帖子审核、广告位与招聘信息管理
