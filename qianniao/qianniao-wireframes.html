公共入口

首次进入小程序的登录与身份分流，所有用户共用。

P1 微信授权登录 → P2 角色选择 → P3 资料完善 → 进入对应端首页（H1 / M1）

酒店商家端

酒店发起报修工单、跟踪进度、管理维保档案、充值续费。

H1 首页 → H2 发起报修（普通/紧急）→ H4 工单详情（看进度、联系工程师）→ H6 验收评价；续费不足时 → H10 充值续费

维修师傅端

工程师接单抢单、上报施工进度、记录材料、完工结算。

M2 工单大厅 → M3 工单详情/接单 → M4 施工上报（进度+材料）→ M5 完工提交 → 酒店 H6 验收后 → M7 收入结算

公共平台

酒店圈信息交流、招聘与广告，双端均可访问（TabBar 入口）。

附：公司端（建议做 Web 管理后台，不进小程序）

思维导图中的「公司端」面向平台运营方，功能为数据管理而非高频操作，建议以 Web 后台承载：

· 工程师管理：查看工程师负责的酒店列表、实时位置与工单进度
· 质量监控：差评工单预警、评价汇总、响应/完工时长统计
· 工单调度：派单规则设置（自动派单 vs 抢单）、紧急工单升级
· 财务结算：酒店充值记录、师傅结算审核、材料费用对账
· 内容运营：酒店圈帖子审核、广告位与招聘信息管理
