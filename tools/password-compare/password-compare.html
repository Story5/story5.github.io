说明：默认按"域名+用户名"匹配。Apple/Chrome 导出的 URL 路径常不同（如 / 与 /login），按域名匹配更实用。
箭头按钮：→ 用 CSV1 密码覆盖 CSV2，← 用 CSV2 密码覆盖 CSV1。覆盖后该行变为绿色"已覆盖"状态并保留在当前视图，点击"撤销"可恢复原密码。
"保存 CSV 到文件"按钮会弹出系统保存对话框，可直接选择并覆盖原 CSV 文件（首次后再次保存不再弹窗，目标文件名显示在按钮上）。需要 Chrome / Edge 浏览器；Safari / Firefox 不支持时会下载 _modified.csv 副本。原列结构（如 OTPAuth）会被保留。
